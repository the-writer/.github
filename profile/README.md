# The Writer

Tools for novelists.

We build focused tools for the repetitive, fiddly parts of writing — worldbuilding, naming, drafting, and publishing — so authors can spend their time on the story.

## Projects

- [creative-workshop](https://github.com/the-writer/creative-workshop) — A desktop naming and worldbuilding tool that generates and organizes character names, place names, official titles, and epithets.
- [Camus](https://github.com/the-writer/camus) — A Markdown-to-static-site publishing tool for building a personal writing site.

## Principles

- **Local-first**: your writing lives on your machine and keeps working offline.
- **Stay out of the way**: fewer interruptions, with tools that sit where you need them.
- **Portable data**: save in open formats and never get locked into one platform.
